Generative Flower — Order × Chaos

対称カオス写像が描く「花」を大量に探索し、回転・鏡映不変な形の地図を作り、 秩序（Order）・複雑さ（Complexity）・図と地（Contrast）の積として美しさを測る試み。

Symmetric Icon を描く

Field & Golubitsky の対称カオス写像（複素平面）：

zt+1 = ( λ + α|z|² + β Re(zn) + iω ) z + γ z̄n−1

この写像は n 回の回転対称を持ち（ω = 0 なら鏡映も加わる）、軌道を長時間重ねると対称な花の模様が現れます。 下のパラメータを動かすか「ランダム探索」で、新しい花を探してみてください。

パイプライン（shape_map.py）

1. 形状特徴

サムネイルを極座標に再標本化し、半径ごとに角度方向の |FFT| を取る。振幅は回転・鏡映で変わらない。

2. 形の地図

標準化 → PCA → UMAP（無ければ t-SNE）で 2 次元へ。HDBSCAN でクラスタ分け。

3. 美しさ

Order × Complexity × Contrast の幾何平均型スコア。中庸を好む逆 U 字（Wundt 曲線）。

4. 較正

人間の一対比較から Bradley–Terry モデルで重み wO, wC, wK を推定。

2 つの地図モード

モード使う周波数何が近くに並ぶか
fullm = 1 … 48対称次数 n も形の一部。まず「何回対称か」で分かれ、その中で形が並ぶ。
petalm = k, 2k, …, 10k対称性を割り算し、花びら 1 枚の描き方だけを比べる。5 回対称と 8 回対称の花でも近くに来る。

美しさの評価関数

Beauty = OrderwO × ComplexitywC × ContrastwK
成分要素考え方
Order回転次数 k（log k 上の釣鐘、中心 6）
鏡映スコア（最大 +35%）
角度コントラスト		4〜10 回対称を好む。円環に近い（ほぼ円対称）ものや直線・スポーク状のものは減点。
Complexityボックス次元 D（中心 1.72）
Lyapunov 指数 λ₁（中心 0.35）		線（D=1）でも塗りつぶし（D=2）でもない、弱すぎず強すぎないカオス。
Contrast輪郭の鋭さ / 余白率（中心 0.45）
もや・孤立点ノイズの少なさ		図と地がはっきりし、適度な余白があること。

一対比較 (i が j に勝った) の集合から、効用 u = wO log O + wC log C + wK log K として P(i ≻ j) = σ(ui − uj) を切片なしロジスティック回帰で推定します。

このページの「好みを学習する」は同じ考え方をブラウザ内で行います。効用を u = wO log O + wC log C + wK log K + Σ vj φj （φ = 対称数・次元・カオスの強さ・余白などの 1 次・2 次項）とし、初期の評価関数（w = 1, v = 0）を事前分布とする L2 正則化付きロジスティック回帰で、選択のたびに全データから再推定します。 ブラウザ版の O・C・K は軌道のヒストグラムから近似計算した値です。

使い方

pip install -r requirements.txt
python shape_map.py --run out/run1                 # 全形の地図 + 美しさ
python shape_map.py --run out/run1 --mode petal    # 花びら地図

入力は symmetric_icons.py の出力（catalog.csv と thumbs.npy）。 出力は shape_map.png, clusters.png, cluster_gallery.png, beauty_top.png, wundt_check.png, map.npz, catalog_scored.csv。
