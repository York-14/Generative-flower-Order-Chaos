3D への拡張

平面の写像（z は複素数）に、実数の高さ w を加えた 3 次元の写像です。

zt+1 = ( λ + κ wt + α|z|² + β Re(zn) + iω ) z + γ z̄n−1
wt+1 = μ wt + δ |z| cos(n · arg z) + ε |z|²
パラメータ役割
κ（結合）高さ w が平面の動きに戻ってくる強さ。0 なら平面の花はそのままで、高さだけが付く。0 以外では形そのものが立体的に変わる。
μ（記憶）高さが過去をどれだけ覚えているか。大きいほど層が厚く、なめらかな起伏になる。
δ（花弁の起伏）花びらの向き cos(n·arg z) に応じて上下させる。n 枚の花弁が交互に反り返る。
ε（お椀形）中心からの距離に応じた上下。負ならお椀、正ならドーム状。

対称性が保たれる理由： w の更新式は |z|、cos(n·arg z)、|z|² という 「z を 2π/n 回しても変わらない量」だけでできています。そのため平面の写像の回転対称 Zn が、 そのまま縦軸まわりの回転対称になります。cos は偶関数なので、ω = 0 なら鏡映（z → z̄）でも不変で、二面体群 Dn の対称性が残ります。

描画： WebGL2 で軌道の点を浮動小数点バッファに加算合成して密度を測り、 2D 版と同じパレット・ガンマ・露出でトーンマッピングしています（外部ライブラリなし）。

ver.2：ボリューム描画

軌道の点を 3D ヒストグラム（128³ または 192³）に数え上げ、密度の場として描きます。 各点は n 回回転（ω = 0 なら鏡映も）で複製してから 8 近傍のボクセルに振り分けるので、サンプル数が 2n 倍になり、 格子の向きによる偏りも出にくくなります。log(1 + count) で圧縮し、σ ≈ 1 ボクセルのガウスぼかしをかけて、 WebGL2 の 3D テクスチャ（R16F・線形補間）に入れます。計算は Web Worker で行うので操作は止まりません。

モード描き方
等値面（ガラス）密度がしきい値を超える面をレイマーチング＋二分探索で求め、法線は密度の勾配から計算。 Schlick のフレネル、屈折（屈折率 1.30–1.60）、内部を通った厚みに応じた Beer–Lambert 吸収。しきい値は「占有ボクセルのうち下位何割を除くか」で、形が変わっても同じ感覚で使えます。
等値面（水銀）同じ面を金属の反射（F0 ≈ 0.78）だけで描画。周囲はプロシージャルなスタジオ照明。
流線密度の勾配 ∇ρ と、方位方向・縦方向を混ぜた向き d の外積 v = ∇ρ × d を流れの場にして積分した線。 v は ∇ρ に直交するので、線はいつも形の表面（等値面）の上を走ります。「流れの向き」が 90° なら等高線のように形を巻き、0° なら花弁に沿って縦に流れます。 線どうしの間隔は格子で保ち、1 本ごとに n 回回転（＋鏡映）で複製するので対称性は崩れません。線上を進む光の粒はテンポに同期します。

ドラッグ中は半分の解像度・少ないステップで描き、止まると全解像度でジッターをずらしながら 24 枚を平均して滑らかにします。 3D テクスチャが使えない環境では点群モードだけになります。
