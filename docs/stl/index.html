Bambu Studio のおすすめ設定（A1 / A1 mini）
  • プロファイル：0.12mm Fine か 0.16mm Optimal
  • 品質 → 壁ジェネレータ：Arachne（細い線を幅の違う 1 本の線で描く）
  • 品質 → 解像度：0.03 mm、円弧フィッティング：オン
  • 品質 → シーム位置：背面（Back） か 整列（Aligned）
  • 品質 → アイロン：上面のみ（Top surfaces）。上面がつるっと仕上がる
  • 強度 → 壁ループ：3、上面パターン：Monotonic line
  • 速度 → 外壁：60〜80 mm/s に下げると輪郭がきれい
  • その他 → ブリム：外側のみ 3 mm（細い突起の剥がれ防止）
